Before filing, search existing issues (open and closed) for duplicates.
- Ask the user before running any command that spends real AI usage, such as a live `npm run eval:live` or a headless `claude -p` run of the skill (#85). Say which command, model, fixtures and `--max-budget-usd` cap you plan to use. Stub and replay runs and `npm run check` need no approval.
